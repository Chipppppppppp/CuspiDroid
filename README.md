[English README](README.en.md)

タイトルバーからスレッド末尾へ移動した後も、上方向へのスクロール操作をすぐに行えます。

書き込み後も既読位置を維持し、成功済みの書き込みを確認処理で再送しません。

CuspiDroid は、5ch と互換掲示板をブラウザライクな UI で閲覧・投稿する Android アプリです。Android 6.0 以降に対応しています。

## 機能

- 複数タブ、検索欄へ自動フォーカスする新規タブ、タブ一覧、ブックマークフォルダー、新規タブと設定内の履歴に表示される未読数を使ったブラウザライクな閲覧
- タブの軽量情報と本文キャッシュを分離し、アプリ終了後の初回起動でもタブ一覧を先に高速表示。本文キャッシュは選択したタブ単位、ブックマーク一覧のフォルダー・未読状態はバックグラウンドで遅延読み込み
- タブ一覧の更新ボタンと上端からのスワイプ更新は、どちらもタイトル・レス数・未読数などの軽量情報だけを更新し、新着本文は取得せず高速に完了。新着が検出されたスレッドは、そのタブを開いた時に本文を遅延読み込み。閉じたブックマークフォルダーの合計未読数も、最新の既読状態を即座に反映
- URL 入力と検索を兼ねたアドレスバー、`find.5ch.io` またはカスタムURLによるスレッド検索。`find.5ch.io` は通常ブラウザと同じWebViewセッションでトップページから検索し、取得した結果をネイティブ表示。HTTP 502時は「検索結果なし」と区別して検索サイトの一時障害を表示
- 次スレ検索では、編集可能な検索語、題名の類似度、連番の連続性を使い、同じ板から候補を少数に絞って板一覧と同じ形式で表示
- 書き込み長押し・メディア／リンク／人気レス抽出・次スレ候補では、共通ダイアログによる同じアニメーション、灰色の枠線、背景暗転を採用し、外側のタップで閉じる表示
- 5chおよびカスタムBBSの板・スレッドをネイティブ表示し、引っ張って更新。スレッドの上下端でも板やタブ一覧と同様の伸縮表現を行い、下端から更新した時は読み込み済みの書き込みを即座に既読化。板読み込みは他のバックグラウンドI/Oから分離し、板一覧は初期表示範囲を優先して描画しながら、スクロール位置に応じて後続スレッドを小分けに読み込み・描画。エッヂなどのカスタムBBSでは履歴・既読情報を一覧生成前に索引化し、スレごとの全履歴走査とBBS設定の反復解析を省略。エッヂ板へのリンクはタイトル・URLの解析や読込開始より先にローディング画面へ切り替え、表示状態と切り離してバックグラウンド読込を開始するため、スレタイやURLの確定前でもタブ一覧へ移動可能。古い板読み込みは中断する。非表示タブは取得データだけを保持してView生成を表示時まで遅延し、板キャッシュのJSON化・保存・不要ファイル整理も専用ワーカーで実行するため、複数の板を開いてもタブ一覧などの操作を妨げない。スレッドから未キャッシュの板へ戻る場合も、即座に板のローディング画面へ移動。「5chリンクを新規タブで開く」が有効なら、スレッドの「板へ」も新しいタブで表示
- スクロール位置と既読位置の保存、未読先頭への移動、未読色分け、順位は100位の灰色から1位の最大の青へ変化し、レス数・勢いは値が大きいほど青く変化する一覧表示と並べ替え
- ツリー表示、返信・リンク・閾値を変更できる人気レスの抽出、4行以上の本文を対象に空白行を除外し、行頭の空白・句読点・引用符・罫線・論理演算子・集合演算子などの連続と行内の連続空白をスコアリングして1行当たり0.75超なら適用するAA自動判定とAA表示、コピペ省略、自分の書き込みとそれへの返信を別色の左バーで示す強調表示、板単位にも対応したNGWord・NGName・NGID管理
- 5ch・エッヂなどの板タイトルバーから、通常の書き込みと同じUIで本文を投稿しながらスレッドを作成し、作成したスレッドを新しいタブで自動的に開けるアプリ内書き込み。エッヂでは正常応答を確認してから完了扱いにし、認証が必要な場合はコードを表示・コピーしてWebViewを開き、認証後に元の書き込みを自動再送。名前・メール履歴、自分の書き込み履歴、認証が必要な掲示板向けのWebView連携
- 長辺を基準に専用の正方形セル内へ全体が収まる画像・GIF・動画の共通プレビュー、スレ内メディアを指に追従して切り替える左右スワイプと全画面ズーム、スレ表示・メディア一覧での強いぼかしと拡大表示でさらに強くなるグロ画像判定のぼかし、各表示中央にメニューやポップアップと共通の背景色・枠線で表示する「閲覧注意」ボタン、「グロ」「死ね」「閲覧注意」などの注意語を含む書き込みとその返信先の全メディアをぼかす既定オンの設定、ImgBBへのアップロードと同じ比率で縮小表示するアップロード履歴と、他のポップアップと統一した削除確認ダイアログ
- ライト・ダーク・プライベートブラウジングに、青を基調とした選択可能なサンプルを加えた4つの組み込みテーマと、端末テーマへの追従。通常時とプライベートブラウジング時に使うテーマを個別に割り当て可能。テーマ選択メニューでは、現在の配色と各候補を5色のプレビュー、明暗・種類、選択マーク付きで表示。組み込みテーマを元に、画面・バー・カード・投稿・入力欄・メニュー・文字・枠線・選択状態・リンク強調・アクセントなど15種類のセマンティック色とシステムバーの明暗を編集してカスタムテーマを作成し、JSONファイルとしてインポート・エクスポート可能。上下アドレスバー、ボタン配置、スワイプジェスチャーもカスタマイズ可能
- 通常表示からWebViewへ切り替えても同じ画面内にアプリ本体の検索バーを維持し、検索候補・デザイン・ボタン配置・メニューをそのまま使用。タブ追加・タブ一覧・ブックマーク操作だけを除外し、通常時の「WebViewで開く」を「アプリに戻る」に置き換えてネイティブ表示へ復帰。ページ内検索も同じアプリ内検索バーで安全に操作し、スレ内・板・板一覧のマッチ箇所は文字色を維持したまま選択状態と同じ緑の背景色でハイライト
- 日常的に使う表示・閲覧・メディア設定から、接続・データ管理・詳細設定へ進む順に並べた設定トップ。目的別の統一カードから各画面へ移動し、ジェスチャーとBBSリンク管理には直接移動。ストレージでは使用量の確認と灰色のキャッシュ削除ボタンを利用可能
- スレッド・メディアキャッシュと、閲覧・既読・書き込み・アップロード履歴の個別管理
- Sync2chによるブックマーク・タブ・既読位置の同期
- CuspiDroidバックアップの作成・復元と、ChMateバックアップからのデータ取り込み
- 既定では暗い緑色の専用テーマを使うプライベートブラウジング。通常タブとは独立したテーマ割り当てを使い、選択した組み込みテーマまたはカスタムテーマの色を画面・検索窓・投稿・メニュー・アイコン・枠線へ一貫して適用し、新規タブでもプライベート状態を維持

## ビルド

Android Studio でこのリポジトリを開くか、次のコマンドを実行してください。

```powershell
.\gradlew.bat assembleDebug
```

最適化済みの release APK を作る場合:

```powershell
.\gradlew.bat assembleRelease
```
