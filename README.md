[English README](README.en.md)

タイトルバーからスレッド末尾へ移動した後も、上方向へのスクロール操作をすぐに行えます。

書き込み後も既読位置を維持し、成功済みの書き込みを確認処理で再送しません。

CuspiDroid は、5ch と互換掲示板をブラウザライクな UI で閲覧・投稿する Android アプリです。Android 6.0 以降に対応しています。

## 機能

- 複数タブ、検索欄へ自動フォーカスする新規タブ、タブ一覧、ブックマークフォルダー、履歴を使ったブラウザライクな閲覧
- タブの軽量情報と本文キャッシュを分離し、アプリ終了後の初回起動でもタブ一覧を先に高速表示。本文キャッシュは選択したタブ単位、ブックマーク一覧のフォルダー・未読状態はバックグラウンドで遅延読み込み
- タブ一覧の更新ボタンと上端からのスワイプ更新は、どちらもタイトル・レス数・未読数などの軽量情報だけを更新し、新着本文は取得せず高速に完了。新着が検出されたスレッドは、そのタブを開いた時に本文を遅延読み込み。閉じたブックマークフォルダーの合計未読数も、最新の既読状態を即座に反映
- URL 入力と検索を兼ねたアドレスバー、`find.5ch.io` またはカスタムURLによるスレッド検索。`find.5ch.io` は通常ブラウザと同じWebViewセッションでトップページから検索し、取得した結果をネイティブ表示。HTTP 502時は「検索結果なし」と区別して検索サイトの一時障害を表示
- 次スレ検索では、編集可能な検索語、題名の類似度、連番の連続性を使い、同じ板から候補を少数に絞って板一覧と同じ形式で表示
- 書き込み長押し・メディア／リンク／人気レス抽出・次スレ候補では、共通ダイアログによる同じアニメーション、灰色の枠線、背景暗転を採用し、外側のタップで閉じる表示
- 5chおよびカスタムBBSの板・スレッドをネイティブ表示し、引っ張って更新。スレッドの上下端でも板やタブ一覧と同様の伸縮表現を行い、下端から更新した時は読み込み済みの書き込みを即座に既読化。板読み込みは他のバックグラウンドI/Oから分離し、エッヂなどのカスタムBBSは一覧を小分けに段階描画。スレッドから未キャッシュの板へ戻る場合も、即座に板のローディング画面へ移動。「5chリンクを新規タブで開く」が有効なら、スレッドの「板へ」も新しいタブで表示
- スクロール位置と既読位置の保存、未読先頭への移動、未読色分け、レス数・勢いなどの一覧表示と並べ替え
- ツリー表示、返信・リンク・閾値を変更できる人気レスの抽出、AA表示、コピペ省略、自分の書き込みとそれへの返信を別色の左バーで示す強調表示、板単位にも対応したNGWord・NGName・NGID管理
- 5ch・エッヂなどの板タイトルバーから、通常の書き込みと同じUIで本文を投稿しながらスレッドを作成し、作成したスレッドを新しいタブで自動的に開けるアプリ内書き込み。エッヂでは正常応答を確認してから完了扱いにし、認証が必要な場合はコードを表示・コピーしてWebViewを開き、認証後に元の書き込みを自動再送。名前・メール履歴、自分の書き込み履歴、認証が必要な掲示板向けのWebView連携
- 長辺を基準に専用の正方形セル内へ全体が収まる画像・GIF・動画の共通プレビュー、スレ内メディアを指に追従して切り替える左右スワイプと全画面ズーム、スレ表示・メディア一覧・拡大表示で共通するグロ画像判定のぼかしと表示ボタン、「グロ」「死ね」「閲覧注意」などの注意語を含む書き込みとその返信先の全メディアをぼかす既定オンの設定、ImgBBへのアップロードと同じ比率で縮小表示するアップロード履歴と、他のポップアップと統一した削除確認ダイアログ
- ライト・ダーク・端末テーマ、上下アドレスバー、ボタン配置、スワイプジェスチャーのカスタマイズ
- 通常表示からWebViewへ切り替えても同じ画面内にアプリ本体の検索バーを維持し、検索候補・デザイン・ボタン配置・メニューをそのまま使用。タブ追加・タブ一覧・ブックマーク操作だけを除外し、通常時の「WebViewで開く」を「アプリに戻る」に置き換えてネイティブ表示へ復帰。ページ内検索も同じアプリ内検索バーで安全に操作
- 日常的に使う表示・閲覧・メディア設定から、接続・データ管理・詳細設定へ進む順に並べた設定トップ。目的別の統一カードから各画面へ移動し、ジェスチャーとBBSリンク管理には直接移動。ストレージでは使用量の確認と灰色のキャッシュ削除ボタンを利用可能
- スレッド・メディアキャッシュと、閲覧・既読・書き込み・アップロード履歴の個別管理
- Sync2chによるブックマーク・タブ・既読位置の同期
- CuspiDroidバックアップの作成・復元と、ChMateバックアップからのデータ取り込み
- ライトモード設定時もダークモード準拠で表示するプライベートブラウジング。通常タブで真っ黒となる画面やバーの背景をかなり暗い緑色にし、検索窓・投稿・メニューなどの少し灰色がかった背景には暗い緑色を使用。眼鏡アイコンは明るい専用色で表示し、通常時に灰色となるあらゆる枠線をプライベート時には少し明るい緑色で統一して、新規タブでも状態を維持

## ビルド

Android Studio でこのリポジトリを開くか、次のコマンドを実行してください。

```powershell
.\gradlew.bat assembleDebug
```

最適化済みの release APK を作る場合:

```powershell
.\gradlew.bat assembleRelease
```
